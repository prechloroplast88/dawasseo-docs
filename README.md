## 갱신 절차

처리방침·고객 지원 본문은 앱 본체 저장소(`dawasseo`)의 `docs/privacy_policy.md`, `docs/support.md`가 작업 기준입니다. 변경 시 본 저장소의 같은 이름 파일도 동일하게 갱신해주세요. 처리방침을 개정할 때는 시행 전까지 적용되는 이전 본문을 `privacy_policy_<개정일>.md`로 보관합니다.
